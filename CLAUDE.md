This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

SyncScript is a headless CMS & collaborative workspace engine (API-first Notion alternative): Fastify + TypeScript (ESM, strict), PostgreSQL via Prisma 7, Redis (ioredis), Socket.io + Yjs for realtime CRDT sync. See ROADMAP.md for the phased commit plan and architecture diagram — implementation follows that sequence.

## Commands

- `npm run dev` — dev server with watch (tsx); `npm run build` — compile via tsconfig.build.json; `npm run typecheck`
- `npm run lint` / `npm run format`
- `npm test` — all tests; single test: `npx vitest run tests/unit/env.test.ts` (or `-t "name"`)
- `npm run db:migrate` / `db:generate` / `db:studio` / `db:seed`
- `docker compose up -d` — Postgres 16 + Redis 7 (note: Docker may not be installed on this machine; the server still boots without them and `/healthz` reports per-service status)

## Architecture notes (non-obvious)

- **Prisma 7 conventions**: config lives in `prisma.config.ts` (not package.json), client is generated to `src/generated/prisma` (gitignored — run `npm run db:generate` after install) and constructed with a driver adapter (`@prisma/adapter-pg`) in `src/lib/prisma.ts`. Import types from `src/generated/prisma/client.js`.
- **CRDT storage**: `Document.ydocState` (Bytes) is the Yjs source of truth; `Document.content` (Json) is a derived snapshot for the Delivery API. Both are written together by the debounced realtime flusher, which also drives Redis cache invalidation.
- **Ownership = membership**: workspace ownership is only `WorkspaceMembership.role = OWNER`; there is no `ownerId` column. `Workspace/Document/ApiKey.createdById` is audit-only (`onDelete: Restrict`).
- **API keys** are stored as SHA-256 hashes (`keyHash`) + display `prefix`; sub-tree scoping (`scopeDocumentId`) is resolved with a recursive CTE, cached in Redis.
- **Two tsconfigs**: `tsconfig.json` (noEmit, includes tests/configs, used by editor+ESLint typed linting) vs `tsconfig.build.json` (emits `dist/` from `src/` only).
- Env vars are validated at startup in `src/config/env.ts` (zod); add new vars there and in `.env.example`.
